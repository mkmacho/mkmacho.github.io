# Photo diary assets

Place public, web-ready images here and add a matching figure block to `../../photo-diary.qmd`.

Use a descriptive filename, a concise alt text that describes what is shown, and a caption below the image. See the root `README.md` for a copy-and-paste example and publishing steps.

Do not upload private images, photos of people who have not agreed to public sharing, or photos that expose a private address or sensitive location.
